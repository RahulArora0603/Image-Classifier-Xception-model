# Convolutional Neural Network based Image Classifier (Xception Model)

A Deep Learning project that classifies images of cats and dogs using the **Xception architecture** with **TensorFlow/Keras**.

The model uses **Transfer Learning** and **Image Augmentation** to improve performance and generalization.

---

# 🚀 Features

* Cat vs Dog image classification
* Built using Xception pretrained model
* Transfer Learning with TensorFlow/Keras
* Image Augmentation for better accuracy
* CNN-based Deep Learning model
* Training and prediction pipeline included

---

# 🛠️ Tech Stack

* Python
* TensorFlow
* Keras
* NumPy
* Matplotlib
* OpenCV

---

# 🧠 Model Architecture

* Base Model: **Xception**
* Technique: **Transfer Learning**
* Type: **Convolutional Neural Network (CNN)**

> Note: RNNs are generally used for sequential data like text or time series, while image classification tasks mainly use CNN architectures.

---


# 📸 Image Augmentation Used

* Rotation
* Zoom
* Horizontal Flip
* Width/Height Shift
* Rescaling
